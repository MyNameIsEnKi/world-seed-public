# Publication Boundary

World Seed uses a deliberate public/private boundary. This repository should establish authorship and demonstrate real progress while protecting unfinished, personal, sensitive, or strategically important work.

## Suitable here

- High-level project descriptions
- Approved development updates
- Public roadmaps without protected implementation detail
- Demonstrations intentionally prepared for release
- Evidence supporting an explicit public implementation claim
- Authorship, provenance, attribution, and contribution records

## Private by default

- The complete Design Bible and master file register
- Unreleased system architecture, schemas, algorithms, and research
- Credentials, secrets, private contacts, personal data, or raw conversations
- Unreviewed proposals presented as canon
- Historical drafts that could be mistaken for current authority
- Third-party material without confirmed publication rights

Every release must record approval, author/source, version/date, status, implementation evidence, contributor credit, and a privacy/rights review. This public repository never silently supersedes the private master.
